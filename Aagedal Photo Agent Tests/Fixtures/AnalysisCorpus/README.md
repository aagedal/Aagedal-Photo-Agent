# Analysis fixture corpus

This directory is the repository-owned baseline corpus for Pixel Analysis, source decoding, and
manual alignment checks. Every artifact is either generated by
`scripts/generate_analysis_fixtures.swift` or is an original JSON contract authored for Aagedal
Photo Agent. The corpus contains no third-party photography, personal data, camera serials,
location history, or vendor production metadata.

## Redistribution and provenance

The authors dedicate all fixture artifacts enumerated by `manifest.json` to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) (`SPDX-License-Identifier:
CC0-1.0`). They may be copied, modified, and redistributed without attribution. The source recipes
and documentation are part of the Aagedal Photo Agent repository and remain covered by the
repository license when distributed as source; the generated fixture artifacts themselves are
CC0-1.0 as recorded in `manifest.json`.

`manifest.json` is the authoritative inventory. It records every artifact's SHA-256, origin, and
expected properties, plus the limits that synthetic assets cannot establish. A test rejects an
unlisted file, a missing file, a digest mismatch, an inaccurate dimension/frame/orientation claim,
or a manifest entry without provenance and expectations.

To regenerate the raster/container files from the repository root:

```sh
swift -module-cache-path /private/tmp/aagedal-analysis-fixture-module-cache \
  scripts/generate_analysis_fixtures.swift
```

ImageIO encoding is reproducible for the checked-in generator on the validation host. A
future macOS codec change may intentionally change encoded bytes; review decoded properties and
then update the manifest hashes rather than silently accepting drift. The two JSON case files are
reviewed source inputs and are not rewritten by the generator.

## Inventory and expected use

| Fixture | Known construction and expected property | Validation use |
| --- | --- | --- |
| `known-pixels-alpha.png` | 16 × 12 RGBA coordinate formula with varying alpha | True-pixel readout, channel/luminance/alpha views, hover alignment |
| `photographic-gradient.png` | 48 × 32 opaque SDR pseudo-photographic gradient and texture | Photographic PNG surrogate, scopes, residual baseline |
| `simulated-scan-halftone.png` | 48 × 32 generated paper tone, halftone dots, and scratches | Scanned print/film surrogate; benign high-frequency counterexample |
| `benign-composite.png` | 48 × 32 generated feathered rectangular patch | Benign edit/composite counterexample; no authenticity conclusion is expected |
| `jpeg-single-q82.jpg` | One ImageIO JPEG pass at quality 0.82 | Known single-compression recipe |
| `jpeg-double-q82-q60.jpg` | Decode of the prior fixture, then a second pass at quality 0.60 | Known double-compression recipe; compare residual energy/patterns, not guilt |
| `orientation-1.tiff` … `orientation-8.tiff` | Same asymmetric 12 × 8 marker with each EXIF orientation | Display/source coordinate mapping at fit, 100%, crop, and magnified hover |
| `animated-two-frame.gif` | Two 12 × 8 generated frames with 0.2/0.4-second delays | Animated-source detection and explicit first-frame behavior |
| `multi-frame.tiff` | The same two generated frames in a TIFF container | Multi-frame detection and explicit first-frame behavior |
| `malformed-truncated.jpg` | Seven-byte truncated JPEG marker sequence | Decode failure, cancellation/error presentation, and fail-closed behavior |
| `metadata-cases.json` | Four synthetic raw-record cases | Stripped, conflicting, non-ASCII/multiline, and malformed metadata rule inputs |
| `c2pa-status-cases.json` | Four typed-state cases, explicitly not signed media | Ensure absence, validity, and signer trust remain independent UI/model states |

The sibling `../EditorialMetadata` corpus is intentionally reused instead of copied. Its generated
RAW XMP sidecar exercises source-write refusal and sidecar preservation; its complex XMP packet
exercises Unicode, namespace conflicts, arrays, structures, and unmodeled properties. Their own
README and manifest govern provenance.

## Coverage boundary

This corpus closes the redistributable **baseline-fixture** gate: the repository now has owned,
reproducible artifacts for known pixels, alpha, SDR, orientation, frames/animation, malformed input,
single/double compression, benign edits, scan/photographic surrogates, metadata-state contracts, and
C2PA presentation-state contracts. It does not turn synthetic surrogates into evidence about a
specific camera, encoder, scanner, editor, signing authority, or AI generator.

The following authentic interoperability additions remain unavailable and are recorded in the
manifest rather than fabricated:

- camera-created JPEG and representative camera RAW originals;
- a decodable HEIC/HEIF artifact (the validation host advertises HEIC but cannot reliably finalize
  it) and an HDR/gain-map source;
- real trusted, valid-untrusted, and invalid signed C2PA media—the JSON cases validate only the
  app's typed state boundary;
- AI-generated examples, because no on-device AI-origin model has passed the separate ship/license
  gate.

Those additions can strengthen device/vendor interoperability and manual color validation later.
They are not claimed by this corpus, and no analyzer accuracy, camera attribution, authenticity, or
AI-origin conclusion may be inferred from the fixtures.
