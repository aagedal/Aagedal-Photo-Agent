## 3.0.0 — YYYY-MM-DD

Photo Agent 3.0 is a large update for 2.x users. **Back up first:** 3.0 replaces 2.x, shares its
data, and older versions may not understand data written by 3.0. Export Known People, templates
and keyword lists from Settings, or copy `~/Library/Application Support/Aagedal Photo Agent/`.
If you sync through iCloud, update every Mac to 3.0. See [known limitations](docs/limitations-3.0.md).

### Highlights

- Caption Workspace: work through a folder with a field navigator, validation, Save & Next, Write & Next, Copy Previous and Fix Next Issue.
- Voice memos: Sony camera voice memos stay paired with their photos, play in Caption, and can be transcribed on this Mac with Apple Speech or Whisper, one photo or a batch at a time.
- Description Assistant: fix grammar, improve wording, draft a caption from the image or dictate one in Bokmål, Nynorsk or English, using a local model or Apple Foundation Models. You always review before it is applied.
- Image Analysis: pixel views, metadata and content-credential inspection, annotations and measurement, timeline and map context with sun direction, and PDF reports.
- Compare two photos side by side, stacked or with a wipe, and keep named Develop versions of a photo.
- Batch Rename with reusable recipes; RAW+JPEG pairs, XMP sidecars and voice memos keep their names together.
- Import photos and videos from Instagram and X posts with the original and its source kept alongside.
- Extract full-resolution stills from videos, with frame timecode markers and 16-bit JPEG XL output.
- Text watermarks, several structured keyword lists at once, and IPTC Media Topics in all published languages.
- Keyboard shortcut editor with a live keyboard preview, and search in Settings.
- Smaller conveniences: type exact values into Develop sliders, eject the memory card when an import finishes, and see roughly how long an import has left.
- Face blurs (Anonymizer) are kept in every export, upload, preview and drag-out, and a render that cannot apply them is refused.
- FTP uploads use a temporary name until complete, retry only what failed, and explain each failure. New servers default to FTPS; SFTP was never supported and old SFTP profiles are flagged.
- Paste IPTC, templates and Develop paste now reach RAW files through their XMP sidecar, and RAW+JPEG pairs keep separate develop settings.
- Hundreds of reliability and speed fixes across browsing, metadata saving, Develop, export, import and quitting, so edits land on the right photo and are never silently lost.
- Experimental: read-only local automation for MCP clients, and C2PA signing (still a preview).

### Changes for 2.x users

- Face scans default to **Fast**, which scans each photo once. For group shots with small or turned faces, choose **Thorough** under Settings ▸ Face Recognition ▸ Scan Mode.
- Develop **Save** writes into the Export Location folder (by default a sub-folder named after the format, such as `Edited_JPEG`) instead of `Edited/`, and never overwrites a file.
- SFTP servers were never supported (macOS's built-in `curl` has no SFTP). Existing SFTP profiles are flagged with a one-click switch to FTPS.
- Your metadata panel keeps showing every field it showed in 2.x. New fields can be hidden in Settings ▸ Metadata.

### Not in 3.0

- Deadline Workspace moves to 3.1. Normal FTP/FTPS upload is unchanged.
